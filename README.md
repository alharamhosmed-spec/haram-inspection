# الجولات التفقدية — تطبيق نظام الجولات التفقدية والصيانة

غلاف تطبيق (PWA) لـ **نظام الجولات التفقدية والصيانة** المبني على Google Apps Script — بنفس «نمط التطبيق» حق بوابة الحرم.
يتثبّت على أندرويد وآيفون والكمبيوتر بأيقونة لوح الجولات ويفتح بشاشة كاملة على دخول الموظفين مباشرة.

**رابط التطبيق:** `https://alharamhosmed-spec.github.io/haram-inspection/`

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي · مستشفى الحرم

## الإعداد (مرة وحدة)
1. النظام **v2.2.0 أو أحدث** (فيه `setXFrameOptionsMode(ALLOWALL)` ووضع التطبيق `?app=1`).
2. النشر: التنفيذ باسم **أنا** · الوصول **أي شخص**.
3. رابط `/exec` في `index.html` ← `APP_CONFIG.GAS_URL`.

## مزايا
- **يفتح على دخول الموظفين** مباشرة (الرقم الوظيفي + PIN).
- **فتح موقع مباشرة:** `…/haram-inspection/?loc=<معرّف الموقع>` (نفس معرّف ملصق QR).
- الجلسة تبقى لين «تسجيل الخروج» أو الخروج التلقائي بعد الخمول.
- التخزين المحلي للغلاف ببادئة `haramInsp_` حتى ما يتداخل مع أي تطبيق ثاني على نفس النطاق.

## التحديثات
- تعديل النظام نفسه: انشره كـ **New version على نفس النشر** — ما تحتاج تلمس GitHub.
- تعديل الغلاف: عدّل الملف وزِد `VERSION` في `sw.js`.
- الأيقونة: `python3 tools/make_icons.py clip`
